# Références de la maquette d’origine

Les fichiers GUIDE_CODE et les données de démonstration proviennent de l’archive du nouveau front-end. Ils décrivent sa version autonome avant connexion au back-end ; leurs instructions ne remplacent pas celles du projet intégré.

Pour le fonctionnement actuel, consulter `frontend/README.md` à la racine du projet et le site `documentation/backend/index.html` (également disponible via le menu Documentation).
